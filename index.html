Rules I build by

Refuse rather than guess

An ambiguous input gets surfaced, never quietly defaulted. A wrong value that looks clean is more dangerous than a visible gap, because nobody goes looking for a gap that appears fine.

Keep models away from the money

Cost and award figures run through deterministic code. Language models do language work; a plausible wrong number feeding a recommendation is a risk no business should carry.

Make checking cheap

Every extracted figure travels with its source, down to the cell. A disputed number is answered with one lookup instead of reopening the original document.

Test the shape of success

A test that only proves something ran stays green while the output is empty. Tests check that the fields that matter are actually filled.
